# Codex Switch v0.2.1

相较 v0.2.0，本版本重点补齐配置库多 API Key 管理、项目 API 同步、模型测试工作流和发布说明自动化。

## 新增

- 配置库支持为同一套 API 配置保存多个 API Key，并通过活动 Key 单选决定全局写入、健康检测、聊天测试和项目模板使用的 Key。
- 全局配置页新增 API 下拉选择和写入预览，可直接选择配置库中的 API 写入用户级 Codex 配置。
- 项目绑定 API 后支持同步已生成项目的模型、API 地址、wire API 和 `.codex/local.env` 中的活动 Key。
- 模型测试页新增成功模型查看弹窗，可查看并复制最近批量测试成功的模型名称。
- 聊天设置支持手动输入自定义模型，并可按接口标准编辑请求体 JSON 模板。

## 改进

- 模型批量测试结果改为更易扫描的网格卡片，并缓存测试结果，重启后仍可查看。
- 模型批量测试并发数可在设置页调整，范围固定为 1-5。
- 聊天模型选择会优先使用批量测试成功的模型，减少误选不可用模型。
- 顶部导航顺序和若干 API/模型展示细节经过整理，配置库、项目配置和模型测试页的信息更清晰。
- API Key 添加按钮改为小号蓝色 `+` 按钮，并与“显示 Key”开关同排显示。

## 修复与发布

- 兼容旧版单 API Key 配置，升级后会自动迁移为单元素 Key 列表。
- GitHub Release 页面将使用 annotated tag 的中文说明，确保 tag 说明和 Release 正文一致。
- Release 仍由 GitHub Actions 在推送 `v0.2.1` tag 后构建 Windows、Linux 和 macOS 三个平台包。
