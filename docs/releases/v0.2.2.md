# Codex Switch v0.2.2

相较 v0.2.1，本版本重点补齐 Codex / Claude 双端配置、项目路由代理、号池、项目 Skills 同步，以及默认协作模板和本地安全边界。

## 新增

- 新增 Codex / Claude 双端配置管理：配置库可标记供应商类型，分别维护 Codex 模型、Claude 默认模型和 Claude 兜底模型；全局页可分别写入 Codex `config.toml` / `auth.json` 与 Claude `settings.json`。
- 新增项目级 Claude 绑定与模板生成：项目配置可同时绑定 Codex 和 Claude，并生成 `CLAUDE.md`、`.claude/settings.local.json` 以及项目启动入口。
- 新增路由代理页：支持按项目启用本地代理，分别配置 Codex 和 Claude 路由规则，并记录最近代理事件。
- 新增协议适配能力：Codex 侧支持 OpenAI 直通、Chat Completions 转 Responses、Responses 转 Chat Completions；Claude 侧支持 Anthropic Messages 直通和 Anthropic 转 OpenAI 兼容上游。
- 新增号池页：可管理多个 Codex 路由代理上游渠道，保存前执行 `/models` 连通性测试，运行时轮询正常渠道并跳过异常渠道。
- 新增项目 Skills 同步：项目模板可从用户或项目技能目录选择 Skills，并同步到 `.codex/home/skills/`。
- 新增 `anthropic_messages` 聊天接口标准，模型测试和聊天请求可按配置或临时设置切换 wire API。
- 默认 `AGENTS.md` 模板新增 PMNote 项目连续性规则、MCP 服务调用规范和中文编码安全流程。

## 改进

- 项目配置详情页补充 Codex / Claude 绑定、模型、Key、模板状态、MCP 和 Skills 摘要。
- 修改项目绑定 API 后，会同步已生成项目的 Codex 配置、Claude 配置和路由代理规则。
- 配置库按供应商类型过滤可用配置，避免把只适用于 Codex 或 Claude 的配置误选到另一端。
- README 已同步路由代理、号池、Claude 项目模板、项目 Skills 和默认模板规则。
- `.gitignore` 与安全说明补充 `.claude/`、本地 `.mcp.json`，降低机器私有配置、绝对路径和本地 agent 状态误提交风险。

## 兼容与测试

- 兼容旧版 `profiles.json`：缺少供应商、Claude 模型、路由代理或号池字段时会使用默认值迁移。
- 新增并扩展路由代理、协议转换、号池、项目模板、Skills、存储和 UI 逻辑测试。
