# Codex Switch v0.2.2

相较 v0.2.1，本版本聚焦项目协作模板和本地安全边界，确保新生成项目能继承更完整的 agent 工作规则，并避免提交机器私有 MCP 配置。

## 新增

- 默认 `AGENTS.md` 模板新增 PMNote 项目连续性规则，明确跨会话恢复、状态层写入、阶段日志记录和多阶段任务路线图维护方式。
- 默认 `AGENTS.md` 模板新增 MCP 服务调用规范，补充 PMNote 服务优先级、项目连续性调用模式、降级链路和工具调用简报格式。
- 默认 `AGENTS.md` 模板新增中文编码安全流程，要求中文源码、Markdown、JSON 和 PMNote payload 使用 UTF-8 without BOM，并避免通过 Windows 文本管道写入中文内容。

## 改进

- README 的文档配置说明已同步默认模板变化，便于使用者理解新项目模板会携带 PMNote、MCP 和中文编码协作规则。
- 安全说明补充 `.claude/` 与本地 `.mcp.json` 忽略规则，降低本机 agent 状态、绝对路径和私有 MCP 配置误提交风险。

## 发布

- 版本号更新为 `0.2.2`。
- 本版本计划通过推送 `v0.2.2` annotated tag 触发 GitHub Actions 构建，并使用中文 tag 说明作为 GitHub Release 正文。
