# Codex Switch v0.3.0

相较 v0.2.2，本版本重点新增 AI 终端、插件体系与脚本中心，并修复了项目 Skills 计数、
项目 API / 路由代理未真正写入项目配置等一系列"显示已保存、实际未生效"的问题。

> 版本号说明：`0.2.2` 发布后累计合入 203 个提交（19 项功能、32 项修复）却一直未更新
> 版本号，导致无法从版本号判断手上是哪一版。从本版本起版本号只有一个来源
> （`src/codex_switch/__init__.py` 的 `__version__`），并写入 exe 文件属性。

## 新增

- 新增 AI 终端：在应用内运行 `codex` / `claude` 等交互式 CLI，支持多开会话、放大查看，
  并在结束时整树回收残留进程。
- 新增终端风险审查闸门：自动应答选择菜单前先做风险判定（安全 / 留意 / 危险），
  按 `关闭 / 严格 / 平衡 / 观察 / 完全放行` 五种模式决定静默放行、仅通知、弹窗授权或直接阻止。
- 危险操作支持系统通知与提示音；需要授权时弹出确认框，超时按"拒绝"处理。
- 终端输出带时间戳：每一次工具调用与对话各自显示发生时刻，只显示新增内容而不重印整屏。
- 终端发送框支持附加图片（选文件 / 剪贴板 / 拖入），也支持发送前浏览该项目的历史提示词。
- 新增插件体系与插件中心：内置插件随包分发，并接入首个内置插件 CodeBuddy 多账号管理。
- 新增脚本中心：支持添加、运行、修改脚本，可后台运行并实时查看日志。
- 新增号池页：管理多个 Codex 路由代理上游渠道，保存前执行 `/models` 连通性测试。

## 改进

- 项目详情页可直接开关项目级路由代理，切换后立即写入项目配置文件。
- 修改项目绑定的 API 后，会同步写入已生成项目的 `config.toml` / `settings.local.json`。
- 终端输入框支持 ↑↓ 翻历史、斜杠指令候选、方向键与回车直接操作选择菜单。
- 修正按键条与输出框之间缺少间距、下拉菜单过窄、禁用按钮不可辨等界面问题。

## 修复

- 修复保存项目后按技能组展开的 Skills 被清空，导致左侧列表显示 0 个的问题。
- 修复切换项目路由代理时只改内存、未落盘，导致 `base_url` 残留本地代理地址
  （终端因此请求未启动的代理并报 502）的问题。
- 修复 AI 终端只在输出停顿后才打时间戳，导致连续的工具调用一个时间戳都没有的问题。
- 修复退出选择器后主屏内容丢失、只有一个选项时无法选择、发送消息后 AI 无反应等问题。
- 修复打包后内置插件全部丢失、插件页面内容堆叠、插件列表为空等问题。

## 兼容与测试

- 兼容旧版 `profiles.json`：缺少供应商、Claude 模型、路由代理或号池字段时按默认值迁移。
- `pyproject.toml` 的版本号改为从 `codex_switch.__version__` 动态读取，避免两处版本号再次漂移。
- 扩充终端、项目、路由代理、插件与界面相关测试。
